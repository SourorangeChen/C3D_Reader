# README media

- `overview.zh-CN.png` and `overview.en.png`: localized introduction graphics with the project's marker-and-segment logo and a screenshot of the real workbench.
- `demo.gif`: looping demonstration for GitHub README rendering.
- `demo.mp4`: higher-quality, smaller video alternative.

All interface captures use the synthetic acquisition generated by `backend/demo.py`. The recorder starts a separate local service on port 8013 with an empty, isolated configuration directory. No experimental recordings or personal library settings are loaded. The browser interface is shown as recorded, including its Chinese controls and the switch to English and a light theme. The surrounding title strip provides bilingual chapter labels. The recording also demonstrates resizing the 3D / signal split.

The banner layout, logo and text are drawn in HTML/CSS/SVG by `scripts/readme-media.mjs`; no external artwork is embedded. Public Sans is loaded from the project's existing font dependency. The reference image supplied for the design is not redistributed.

To regenerate on macOS from the repository root, install the project dependencies and Playwright Chromium, build the frontend, and provide an FFmpeg executable:

```sh
npm run build
npx playwright install chromium
FFMPEG_BINARY=/path/to/ffmpeg node scripts/readme-media.mjs
```

The script uses the project's `.venv/bin/python` and existing Python dependencies. FFmpeg is only a media-authoring dependency; it is not required by C3D Reader. Intermediate recordings are written to the ignored `.local/readme-media/` directory. The generated images, GIF and MP4 are intended for publication and are tracked in Git.
