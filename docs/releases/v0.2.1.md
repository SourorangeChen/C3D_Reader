C3D Reader v0.2.1 removes local build-machine paths from distributed dependency metadata and switches published validation statistics to reproducible synthetic data.

- Remove installation-only `RECORD` and `direct_url.json` files before signing; preserve runtime package metadata and third-party licenses.
- Check packaged files, ZIP members and frozen Python modules for the builder's source/home paths, common credential formats and non-distributable data/configuration files. The check complements manual privacy review.
- Replace real-dataset statistics in current documentation and release notes with the generated walking fixture: 800 frames, 35 markers, 4 analog channels, 100 Hz points and 1,000 Hz analog samples.
- Keep the existing 3D workbench, synchronized plots, native opening/drag-and-drop, gait events and full-rate CSV export.

**Install:** Download `C3D-Reader-0.2.1-macOS-arm64.dmg`, open it, and drag C3D Reader into Applications. A ZIP archive and SHA-256 checksums are also provided.

**Compatibility:** Apple Silicon, macOS 14+. No Python or Node.js installation is required by users.

**Verification:** 26 Python/API/packaging tests, 8 browser tests and 5 packaged desktop integration tests. The standalone service is checked against the generated synthetic acquisition, including its last frame and full-rate CSV export. The DMG application is compared with the ZIP and its signature verified.

**Signing:** Ad-hoc signed; not Apple Developer ID signed or notarized. macOS may require the Privacy & Security “Open Anyway” confirmation for a trusted download.

**History:** Previous installation attachments are withdrawn. Updating current files and release notes does not erase earlier Git commits, source archives or copies already downloaded. Earlier documentation contained aggregate validation statistics, not participant identities or original recordings.
