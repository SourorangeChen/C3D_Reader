C3D Reader now includes a self-contained macOS desktop application.

- Double-click the app to launch; no Python, Node.js, terminal or external browser setup is required.
- Drop a C3D file into the window, use ⌘O / native Open, or open a recording through Finder / the Dock.
- Open a data folder with ⌘⇧O. CSV exports use a native save dialog.
- The bundled service reads files in place and handles large acquisitions without copying them. It shuts down when the app exits.
- Includes the existing 3D marker workbench, synchronized signals, gait events, frame controls, interval selection and full-resolution CSV export.

**Download:** `C3D-Reader-0.2.0-macOS-arm64.zip`. Unzip and move `C3D Reader.app` into Applications.

**Compatibility:** Apple Silicon (arm64), macOS 14+. Intel builds are not included.

**Signing:** This build is ad-hoc signed and has not been Apple Developer ID signed or notarized. A download onto another Mac may be blocked by Gatekeeper. If you trust this project, use the macOS Privacy & Security “Open Anyway” confirmation. Do not disable system security checks.

**Verification:** 23 Python/API tests, 8 browser tests, and 5 desktop integration tests passed locally. The desktop suite also passed against the packaged app. A bundled-service smoke test opened a private ~645 MB, 51,065-frame acquisition with 296 analog channels. No participant recordings are included.

The attached `SHA256SUMS.txt` verifies the ZIP. All processing remains local; there is no telemetry or recording upload.
