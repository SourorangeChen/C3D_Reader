# C3D Reader v0.4.6

## 简体中文

让报错跟随界面语言，播放更流畅，并完成一轮内部重构。视频同步和导出等功能与 0.4.5 相同。

- **报错跟随界面语言**：读取文件、导出、信号对齐和自动对齐等报错现在按所选语言显示。此前英文界面下仍会出现中文报错；出现报错后再切换语言，已显示的报错也会随之切换。
- **补全英文翻译**：「时间对齐」对话框的关闭按钮和信号采样数在英文界面下不再显示中文。
- **播放更流畅**：播放时，顶栏、左侧图标栏、文件列表、通道列表和状态栏不再每帧重新渲染，只有时间轴和检查器随帧更新。
- **切换时不再闪现旧曲线**：切换文件、通道或观察区间时，信号图不会短暂显示上一条曲线。

内部改进：界面拆分为独立组件，状态逻辑移入可测试的模块；CI 新增 Python 静态检查、代码格式检查和 Vitest 单元测试。

本地通过 85 项 Python 测试、27 项单元测试、48 项浏览器用例和 11 项桌面集成用例；GitHub Actions 在 macOS 上构建并测试了开发版与打包后的应用。两项依赖真实录制的自动对齐验收测试未在 CI 中运行。

适用于 Apple Silicon、macOS 14+。ad-hoc 签名，尚未经过 Apple 公证；首次启动如被拦截，可在系统设置「隐私与安全性」中选择「仍要打开」。

## English

Errors now follow the interface language, playback is smoother, and the interface code has been restructured. Video synchronization and export behave as in 0.4.5.

- **Errors in the selected language**: errors from reading files, exports, signal alignment and automatic alignment now appear in the selected language. Previously the English interface could still show Chinese errors; an error already on screen also switches when you change the language.
- **Complete English translation**: the **Time alignment** dialog's close button and its sample count no longer show Chinese in the English interface.
- **Smoother playback**: during playback the header, left rail, file list, channel list and status bar no longer re-render on every frame; only the timeline and inspector update with the frame.
- **No stale plot when switching**: switching file, channel or observation range no longer briefly shows the previous signal.

Internal: the interface is split into separate components and its state logic moved into testable modules; CI now runs Python linting, formatting checks and Vitest unit tests.

Local validation passed 85 Python tests, 27 unit tests, 48 browser cases and 11 desktop integration cases; GitHub Actions built and tested both the development and packaged app on macOS. Two automatic-alignment acceptance tests that need real recordings were not run in CI.

Requires Apple Silicon and macOS 14+. Ad-hoc signed, not Apple notarized; use **Open Anyway** in macOS **Privacy & Security** on first launch if prompted.
