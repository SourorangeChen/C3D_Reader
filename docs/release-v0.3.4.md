# C3D Reader v0.3.4

## 简体中文

增强按钮的辨识度，让可点击的操作更容易找到，保留现有工作台布局和 CSV 导出行为。

- 普通操作按钮采用中性填充与清晰边框，覆盖视角、3D 工具、XYZ 曲线开关、播放控制和观察区间操作。
- 打开、导出、播放及确认操作使用蓝色主按钮；已开启的开关使用蓝色选中状态，悬停时继续保留提示。
- 深浅主题分别定义常态、悬停、按下和选中配色，保持文字与图标清楚可辨。

本地通过 16 项浏览器用例和 8 项桌面集成用例，并检查中英文、深浅主题及四种窗口宽度。README 简介图与演示已同步更新，均使用合成数据。

适用于 Apple Silicon、macOS 14+。ad-hoc 签名，尚未经过 Apple 公证；首次启动如被拦截，可在系统设置「隐私与安全性」中选择「仍要打开」。

## English

Makes action buttons easier to identify while preserving the workbench layout and CSV export behavior.

- Neutral fills and clear outlines distinguish ordinary actions, including view selection, 3D tools, XYZ toggles, playback controls and frame-range actions.
- Opening, exporting, playback and confirmation use blue primary buttons. Enabled toggles retain their blue selected appearance when hovered.
- Light and dark themes define normal, hover, pressed and selected colors to keep labels and icons legible.

Local validation passed 16 browser cases and 8 desktop integration cases, with visual checks in both languages and themes at four viewport sizes. README images and demonstrations are updated using synthetic data only.

Requires Apple Silicon and macOS 14+. Ad-hoc signed, not Apple notarized; use **Open Anyway** in macOS **Privacy & Security** on first launch if prompted.
